请在 dsh-workspace-plus 插件中实现侧边栏视图配置增强。先阅读现有代码与仓库规范，再直接修改代码，完成必要的验证。

背景：
本插件用于增强 DSH 的工作区与会话侧边栏，已有工作区分组树、时间视图、会话置顶、搜索和外观自定义等能力。现在需要让分组方式、排序方式和归档筛选能够独立配置。

一、视图配置入口
在侧边栏标题栏增加或完善"视图配置"按钮，点击后展示三个区域：
- 分组方式 / 排序方式 / 筛选会话
当前选项应有明确的选中标识。按钮图标随当前视图变化。
插件设置卡片也提供等效配置，两处使用同一份持久化状态。

二、分组方式（四种视图）
1. 按工作区：各工作区独立展示，不按工作区名称中的"/"构建上层分组树。
2. 按工作区树：保留现有按名称路径分组的树形视图，作为默认值。
3. 单列表：去掉工作区容器，直接展示会话列表。
4. 按时间：保留现有时间分桶视图，并支持"最近优先 / 最早优先"。
各视图都应支持未分组会话，保留现有会话状态、置顶、外观与必要的操作能力。

三、排序方式
- 手动排序：使用宿主提供的工作区和会话顺序。
- 最近更新：按更新时间降序展示。
排序与分组方式独立，可以组合使用。最近更新仅改变显示顺序，不得写回宿主顺序，也不得修改工作区或会话名称。时间视图使用自己的时间方向，通用排序选项应明确体现其受限状态。自动排序时禁用工作区和会话的拖拽重排；恢复手动排序后恢复原有拖拽能力。"按工作区"视图中的工作区重排不得意外修改名称或所属名称分组。

四、筛选会话
- 隐藏已归档：默认。 - 全部对话：显示普通与已归档会话。 - 仅显示已归档。
使用宿主提供的归档状态，不维护另一套归档数据。筛选统一作用于四种视图、搜索结果和置顶区域。
已归档会话应：有清晰的归档标识；不直接打开，提示先取消归档；可通过行上的恢复按钮调用宿主取消归档接口，旧宿主没有该接口时禁用恢复入口；保留原来的置顶配置，但归档期间不出现在置顶区域；显示归档时可出现在普通列表，恢复后重新进入置顶区域。
仅归档模式隐藏没有匹配会话的工作区及空分组。归档结果为空时提供清晰空态和"查看全部对话"入口。

五、搜索与去重
搜索必须遵守当前视图和归档筛选，并保留原有名称匹配能力。同一会话在当前界面只展示一次，避免置顶区域与普通列表重复。保留现有对子任务会话、空白会话的可见性规则。

六、状态持久化与兼容
将分组方式、排序方式、归档筛选和时间方向分开存储。建议字段：viewMode: workspaces | projects | flat | time；sortOrder: manual | latest；archivedFilter: hide | show | only；timeDirection: latest | oldest。
兼容旧版 sortMode 配置，让旧的时间视图及时间方向继续生效。切换一个选项不得重置其它独立选项，也不得丢失已有展开状态、置顶记录或外观配置。

七、范围与实现约束
本次只实现视图配置增强。不要增强或重构会话右键菜单，不要新增永久删除、复制目录、复制会话 ID 等菜单功能。不要引入额外插件依赖，不要提交、发布或重启服务。保留工作区内已有的未提交改动。采用简洁、可维护的实现，不使用嵌套三元表达式，非必要不新增 useMemo/useCallback。

八、验证与交付
- 四种视图与三种归档筛选的组合。
- 搜索遵守筛选，未分组会话正常显示。
- 置顶会话不重复，归档与恢复不丢失置顶配置。
- 最近更新排序不改变宿主数据，切回手动排序恢复原顺序。
- 自动排序禁用拖拽，按工作区重排不改名称。
- 旧配置兼容，以及标题栏与设置卡片状态同步。

设计三条主线

  • 四轴独立持久化：viewMode / sortOrder / archivedFilter / timeDirection 各存各的键，改一个不动其余；旧 sortMode（manual / latest / oldest）在读取时折算，不迁移、不重写。
  • 一份选项表、两处渲染：标题栏弹窗与设置卡片都读 VIEW_OPTIONS / SORT_OPTIONS / ARCHIVE_OPTIONS / TIME_DIRECTION_OPTIONS，永远不漂移。
  • 一个行可见性门：sessionRowVisible（血缘 + 空白规则）叠加 archiveVisible（宿主归档状态），四种视图、搜索与置顶区共用；渲染层再用一次去重集合保证「一会话一行」。
最容易踩的坑：已归档的置顶会话。沿用旧的 pinned 过滤，它既进不了置顶区、又被普通列表排除，会彻底消失。最终判定改用 isTrayOwned = pinned && !archived——置顶记录原样保留，归档期间回到普通列表，取消归档自动回置顶区。
